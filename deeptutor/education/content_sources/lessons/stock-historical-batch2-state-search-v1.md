# 有限状态：最少步数与取石子策略

适用：数学拓展讲解。以下内容由本机已有旧书的数学结构独立改写，已做精确计算或有限枚举核验；课程年级、难度和正式测试资格仍待教学审核。用于 Chat 的完整讲解案例，不在 Chat 发起 Quiz，不据此自动认定学生掌握或升级。

## 核心方法
把状态写全，才能判断两条路径是否真正到达同一局面。量杯状态包含四个水量；取石子状态包含剩余量、轮到谁和累计奇偶性；循环排程还要检查尾部与开头的连接。

## 讲解案例1：四个音符的循环排程

条件：用1、2、3、4表示四个音符。每行将它们各写一次，排成24行循环；每种排列恰好出现一次。相邻两行中，每个音符的位置最多移动1格；同一个音符不能连续3行都在第一位，也不能连续3行都在第四位。最后一行与第一行也相邻。给出一个排程并说明如何检验。

结论：存在24行排程；须同时满足排列不重复、相邻移动限制和首尾循环限制。

## 讲解案例2：最少倒水次数

条件：有容量分别为10、10、5、4升的四个无刻度容器，开始两只10升容器装满水，其余为空。每次只能从一只倒入另一只，直到倒出容器空了或接收容器满了；不许加水、洒水或中途凭目测停止。要让5升和4升容器中各有3升，至少倒多少次？给出过程，说明如何检验最少性。

结论：最少11次。

完整推导：按容量10、10、5、4的次序记各容器水量。一个11次方案为：
(10,10,0,0)
(5,10,5,0)
(5,6,5,4)
(9,6,5,0)
(9,2,5,4)
(9,7,0,4)
(9,7,4,0)
(9,3,4,4)
(9,3,5,3)
(9,8,0,3)
(4,8,5,3)
(4,10,3,3)
每个相邻状态只涉及两只容器，每次转移量等于“源水量”和“目标空余容量”中的较小值。为证明最少，可从起点按倒水次数逐层枚举全部可达状态，并合并重复状态；第0至10层均无末两项为3、3的状态，第11层首次出现。只给出11次方案证明可行，还需这一逐层穷尽论证才能证明最少。

## 讲解案例3：奇偶取石子

条件：两位玩家轮流从一堆石子中取1、2或3颗；剩余不足3颗时不能多取。石子取完后，以自己累计取得的颗数为奇数者获胜。两人都作最佳决策。分别分析开始有15颗和13颗时谁能保证获胜；有15颗时，先手第一步应取几颗？用包含累计奇偶性的状态表说明，不要把规则当成“取走最后一颗就赢”。

结论：15颗时先手能保证胜且第一步须取2颗；13颗时后手能保证胜。

完整推导：总数为奇数，最终必有且只有一人取得奇数颗。状态需记录剩余数、轮到谁及先手累计数的奇偶性。剩余0时由该奇偶性判先手胜负；先手回合有一个后续状态能赢即可，后手回合则须所有合法后续状态都能让先手赢，先手才可保证胜。由0颗向上递推：15颗时首取1、2、3对应先手能否保证胜为否、是、否；13颗的起始状态为先手不能保证胜，因此后手可保证胜。

## 教学提醒
区分可行与最优：展示一个11步方案不等于证明最少；逐层穷尽状态后才能排除10步以内的方案。取石子游戏按累计奇偶决定胜负，并非取末颗就赢。
