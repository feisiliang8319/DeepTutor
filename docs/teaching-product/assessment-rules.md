# 已批准的学科评估与晋升规则

2026-09-27，用户在审核后批准执行。仅在隔离开发/合成数据中实施；不授权生产迁移。

- 学校年级是背景；各学科在特定课程体系中独立保存学习年级。家长指定起点不是掌握证据。
- C=60至不足80，B=80至不足90，A=90至100；不足60未达标。竞赛70分使用独立“竞赛达标”，不混入普通成绩档位。
- 日常完整测试20题/50分钟，单元25题/70分钟，期末和提前晋级35题/90分钟。短测10题/20分钟作为轻量入口，不直接晋升。
- 普通正式试卷难/中/易按15%/65%/20%配额，以最大余数法取整。20题3/13/4，25题4/16/5，35题5/23/7。分值独立于题数配置，考试按总分归一为100。
- 单元/期末覆盖规定单元与核心能力；单元及期末均需80分，核心能力不能用其他分数抵消。每个考核单元至少2道已标注核心题。
- 正常升级：同一学科、课程体系、年级的全部必修单元和期末均达标，系统自动升一级。
- 提前晋级：综合考核90分，且被跳过各年级的必要知识已有有效考核证据，取得资格，由关联家长确认。只考当前年级不能自动获得跨多级资格。
- 竞赛仅限明确分类为STEM的课程，数学优先；语言、人文等课程不提供竞赛入口，服务端同样拒绝竞赛请求。
- 竞赛：20道该学科/等级的竞赛难题，90分钟。至少70分且评分已确定，自动升本学科一个年级，不以基础补测作为前置条件。
- 竞赛晋级后提供一次可选基础补测：是→晋级前年级的核心知识35题/90分钟；否→结束本轮，记为未补测而非基础已掌握。补测仅诊断知识缺口，结果进入Chat补弱，不再升级也不撤销竞赛晋级。题库不足不发卷、不消耗选择；重复确认恢复同一试卷。
- 未达标后把完整复盘送入Chat，进行订正交流后用覆盖和难度一致的新卷重测，不允许立即反复刷同一套答案。
- 正式卷只用已审核且可批改题目；排除历史作答、已见试卷、相同规范题面、已标记同源/近似变式。题库不足明确报告，不降难、不重复、不用未经审核的新题填充。
- 原始答卷不可改；服务器计时和保存草稿，超时仅按截止前已保存内容交卷；断线恢复不重置时限。
- 待复核或部分得分未确定时不判晋升。数值复核保留原始作答和历次裁定；一次成绩至多触发一次升级。
- 上述“升级”仅改变平台中该学科的学习安排，不修改学校实际年级；新年级没有已发布课程时明确显示课程待准备。
