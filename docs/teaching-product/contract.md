# 教学产品收缩契约

已批准的产品方向，2026-09-27。开发基线为生产提交 1e0e1ece 及本地保存的 61 个生产源文件定制（47d2f98e）；本轮不混入上游版本升级。此文档不表示已经部署。

## 产品边界

| 入口 | 负责 | 不提供 |
| --- | --- | --- |
| 学生 Chat | 提问、教学、Research、上传作业批改、Quiz 讲解与纠错 | Quiz 出题、答卷、测试评分；模型、Agent、知识库和记忆配置 |
| 学生 Quiz | 发卷、作答、提交、正确性及标准答案 | 教学讲解；解释自动进入 Chat |
| 家长 | 自己孩子的目标、进展、学习记录、家庭资料注入 | 其他家庭的数据、代学生提交测试 |
| 管理员 | 知识库、教学数据、模型、记忆、教学 Agent、账户与权限 | 面向学生的通用工作台 |

恰好一个管理员，家长总量不设上限。每个家长最多关联 5 个学生（停用账户仍保留记录并占用关联名额）；每个学生恰好关联一个家长。平台学生总量随家长数量扩展。

账户及授权链严格为管理员 → 家长 → 学生。管理员只创建、管理家长并分配其模型、主库和功能权限上限；学生在管理端只留记录，不提供学生配置操作。家长创建并管理自己的学生，在已获权限范围内分配模型、知识和功能，不能越权。撤销家长授权立即收窄其学生的有效权限。账户使用独立登录。身份、家庭归属与访问控制以服务端记录为准，不信任前端角色、JWT 旧角色、用户名前缀或请求传入的家长标识。

知识库统一检索，先限定授权范围再检索排序。主库与家庭资料保留来源，家庭资料默认只对所属家庭及指定学生可见。公开晋升必须由管理员明确执行。学生不手动选库。

教学数据保留题目快照、原始作答、批改依据和学习事件；记忆是可追溯、可纠正的派生结果，不能覆盖原始作答，也不能因一次聊天宣布掌握。Chat 与 Quiz 共享学生学习状态。

Agent 配置描述教学行为；模型配置描述执行资源。有效配置由系统默认、管理员策略和学生目标组合得出，并提供实际生效结果。学生只表达学习需求，服务端选择模型和工具；无法执行时明确报告失败。

## 裁剪与复用

保留现有认证、会话、文件上传、RAG、模型适配、教育领域模型和不可变作答机制。Research、推理、可视化变成教学内部能力。学生导航收缩为 Chat / Quiz，家长和管理入口按角色独立。

通用 Agents Hub、外部 CLI 代理、导入开发会话、多层工作区记忆维护、通用空间与非教学应用退出教学产品入口。兼容代码暂保留以便回退；隐藏菜单不能替代 API 权限。旧的单家庭 parent 前缀权限与手选知识库/模型不进入新产品路径。

## 实施顺序与验收

1. 事务身份库与显式迁移：一个管理员、学生唯一家长、跨家庭拒绝、旧令牌不保留旧权限。
2. 三角色 API / 页面收缩：越权直连也拒绝，家长只读自己孩子的作答。
3. Quiz → Chat：提交和批改保持幂等，所有教学上下文持久化并自动关联 Chat；重试不重复批改或开会话。
4. 教学路由：授权资料统一检索、后台模型策略、可追溯学习状态与记忆更新。
5. 隔离数据下完成真实桌面/手机浏览器流程，再准备生产迁移、差异及回退包。

生产账户、资料和学习数据当前不修改。旧自动选库实验不单独发布。发布前必须完成两家庭隔离、重试恢复、权限撤销、Chat 无 Quiz、Quiz 无教学讲解的验证，并明确仍需人工教学评估的内容。


## 本轮追加确认

学生可配置外观与体验：柔和主题、昵称、学习伙伴、字号、动效，按账号保存；这些不属于模型或教学权限。系统只支持简体中文、繁體中文、English 三个显示选项。DeepTutor 建立自己的儿童友好视觉体系，脱离 ERMS 设计规则；有品味、有个性、允许适度动态交互，同时避免大面积纯白、纯黑与刺激性效果。
