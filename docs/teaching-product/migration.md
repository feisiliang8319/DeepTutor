# 教学产品身份迁移

## 单一权威

教学身份库位于运行目录 data/system/auth/teaching.sqlite3。显式迁移成功后，它是账户与家庭关系的唯一写入源；历史 users.json 仅保留回退证据，运行时不双写。数据库存在但损坏、结构不符或约束不成立时拒绝读取，不退回旧账户。旧模式仅用于迁移前兼容，不具有多家庭产品能力。

迁移逐项指定旧账户的新角色、学生的家长用户名；保留稳定 user ID、密码哈希、头像和原工作区。禁止根据用户名猜测角色或家庭。源记录无稳定 ID、缺少映射、孤儿学生、重复管理员或停用管理员时拒绝。新增家长应在获准的账户迁移准备中明确提供；不把原管理员同时当家长。

命令默认 dry-run，只输出数量与非敏感校验结果。--apply 在同目录临时库完成事务和完整性校验，再原子创建正式文件；目标已存在时拒绝覆盖。源 JSON 与认证密钥不修改。

## 切换前

停写窗口内备份账户、授权、教育数据库及会话；备份只留受控主机。核对身份映射与 learner_profiles 的旧用户名关联，转换为稳定 user ID。家庭访问以新关联为准。对旧的管理员家庭资料明确分配来源和可见范围；未经确认不自动公共化。运行账户 dry-run、学习档案映射 dry-run 及两家庭隔离验收，提交可审查差异后取得生产切换批准。

## 回退边界

切换前可以直接使用原版本与未变的 JSON。切换后新增账户、学习记录或家庭关系不得靠删除新库回退；应先停写并导出经核对的增量，再恢复整套一致快照或修复前进。运行中不能通过移走新库重新启用旧权限。发布清单需记录应用版本、数据库快照、迁移报告及恢复演练结果。
