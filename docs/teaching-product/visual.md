# 教学界面视觉约束

按用户补充指令使用 Taste-Skill，产品实现与浏览器验收继续遵循 design。采用现有 React / Tailwind / Geist / Lucide，避免新增设计系统。

设计方向：学生、家长和管理员共用柔和、低刺激的视觉语言。布局变化 4，动效 2，学生信息密度 3；后台可提高密度，但不引入额外装饰。保留 DeepTutor 品牌；重构导航与任务入口已获授权。原版页面是通用工作台，功能模式、工具与模型选择挤占学习区，应退出学生路径。

颜色：灰绿浅底 #f2f5f0、较深侧栏 #e6ede6、阅读面 #f7f9f4、正文 #2d4038、辅助文字 #586c60、主操作 #386853。柔和来自表面层次，不靠降低正文对比度。不用大面积纯白或纯黑，不加入闪烁、自动循环动画或无意义插图。

控件：统一 10px 圆角、清晰边框、最小 40px 高度（手机 44px）、一致焦点环；输入字号 16px，避免手机输入缩放。按钮、下拉框、附件、结果与错误状态都要验收；禁用不冒充可用，错误不只靠颜色。学生可从精心搭配的林地、雾蓝和暖杏三组主题中选择，设置昵称、学习伙伴、字号和动效；不提供需要自行调配对比度的任意颜色面板。外观按账号保存，动效尊重系统减少动态效果的设置。

最高风险：内容过密、手机控件溢出、柔和配色导致对比不足。验收必须覆盖桌面与手机的 Chat、Quiz、家长及管理路径，检查输入、发送中、错误、加载和空态，记录真实截图。当前文档不是 UI 验收完成声明。
